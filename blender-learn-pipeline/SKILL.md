# Blender 3D 学习流水线

把「学一个东西」从线性阅读升级成一条**固定流水线**：

```
拆到底层 → 建体系 → Blender 3D 可视化 → 讲清本质 → 自检闭环
```

核心立场：**看懂每一行字 ≠ 脑子里有画面**。抽象概念的困难不在公式难，而在它们本质是结构或过程——结构与过程必须被立起来看。本技能把「立起来看」固定为流水线的第三段，且一律用 Blender 无头渲染出真 3D 产物，不交付想象中的图。

## 流水线总览

| 阶段 | 产出 | 出口判据（不过不放行） |
|---|---|---|
| 1 拆到底层 | 隐含假设表 + 原子事实清单 + 推理链 | 推理链每步都能写出「由 A+B 推出 C」 |
| 2 建体系 | 三层依赖 DAG（核心/支撑/延伸）+ 跨学科坐标 + **3D 主体对象选型** | 已明确「哪个结构值得立起来看」 |
| 3 Blender 3D 可视化 | ≥3 视角 PNG + 360° 环绕 mp4（真机渲染） | 文件真实存在、中文标注不糊、渲染日志无报错 |
| 4 讲清本质 | 一句话本质 + 类比 + 失效边界 + 存在动机 | 本质句能对应到 3D 画面中的具体镜头 |
| 5 自检闭环 | 3–5 道自检题 + 3D 复述测试 | 用户（或自测）能看着渲染图把推理链讲一遍 |

各阶段详细 checklist 与模板见 `references/pipeline-stages.md`；Blender 无头渲染的命令、字体、报错处理见 `references/blender-headless.md`。

## Stage 0 — 定学习档位

先判档，再进流水线；用户没说就按「精通」走全流程，并在交付开头注明档位假设。

| 档位 | 触发语 | 裁剪 |
|---|---|---|
| 精通（默认） | 「系统学 / 搞懂」 | 全五段，Stage 1–5 不裁 |
| 速览 | 「快速过一下 / 速览 / 大概讲讲」 | 只做：推理链 → 主体选型 → 1 张主视角静帧 → 一句话本质 + 类比 → 2 道自检；跳过 DAG、环绕视频、复述测试 |

## Stage 1 — 拆到底层

1. **列隐含假设**（3–6 条）：标注每条是「承重假设（拆掉就塌）」还是「情景假设（仅在特定范围成立）」。
2. **找原子事实**：不可再分、可核验的基础事实（定义 / 公理 / 实验结论 / 守恒量），每条标来源类型；无法核验的标「待核验」，禁止编造。
3. **重建推理链**：从原子事实一步步推到目标概念，每步标注「由 A + B 推出 C」。

推理链是后续一切的主干：Stage 2 的 DAG、Stage 3 的镜头、Stage 4 的本质句都从它生长。

## Stage 2 — 建体系

产出三层依赖 DAG（Mermaid 或 SVG）：

- **核心层**：主题本身及直接定义
- **支撑层**：理解它必须先懂的前置概念
- **延伸层**：它进一步支撑的上层概念与应用

并给出跨学科坐标（同一概念在不同学科的视角差异）。

**本阶段独有步骤——3D 主体选型**：从推理链和 DAG 里挑出「最值得立起来看的一个结构」，判定它的类型：

| 主体类型 | 例子 | Blender 表达 |
|---|---|---|
| 层次 / 体系结构 | 知识塔、网络协议栈、组织架构 | 分层块体 + 标注 |
| 过程 / 流转 | 数据流、流水线、反馈回路 | 管道 / 环 + 移动指示体 |
| 空间关系 | 场、轨道、曲面、嵌套 | 曲面 / 粒子 / 环绕相机 |
| 机制原理 | 齿轮咬合、杠杆、解剖结构 | 组装体 + 运动部件；**需精确尺寸/真实结构时走 SolidCraft CAD 桥接**（参数化建模 → STL → Blender 渲染，见 references/blender-headless.md 二点六节） |

若概念本身无空间性（如纯定义类），仍可用 Blender 做隐喻式表达（塔 / 管道 / 齿轮），但**必须在交付物中标注「此为隐喻非实体」**，防止误导。

> 🔴 CHECKPOINT：主体类型已判定，且能说出它承载了推理链的哪几步——说不出就退回重选，不得进 Stage 3。

## Stage 3 — Blender 3D 可视化（核心段）

工作法（顺序执行，不跳步）：

1. **写镜头清单**：主视角 / 等轴视角 / 俯视角三张静帧的构图意图 + 环绕镜头要突出什么。镜头必须服务推理链，不为炫技加镜头。
2. **写场景脚本**：新建 `[主题]_scene.py`，`sys.path` 指向本技能 `scripts/` 目录，`import blender_learn` 复用助手库（清场 / 打光 / 中文标注 / 多视角渲染 / 环绕渲染）。**优先复用 `teaching_components` 参数化组件库**：分层塔 `layered_tower`（层次体系）、管道流 `pipeline_flow`（过程流转）、齿轮咬合 `gear_pair`（机制原理）、轨道系统 `orbit_system`（空间关系）——传参数出场景，无适配形态再手写建主体。环绕镜头用 `render_turntable(OUT, prefix="[主题]—360环绕")` 以满足交付命名。命令与脚本骨架见 `references/blender-headless.md`。
3. **真机渲染**：

   ```bash
   BLENDER="blender.exe 的完整路径"   # 按本机替换，如 C:\Program Files\Blender Foundation\Blender 5.2\blender.exe
   "$BLENDER" --background --factory-startup \
     --python "[主题]_scene.py" -- --out "输出目录" --frames 24
   ```

4. **自检**：产物文件存在且非 0 字节、用看图工具确认中文标注渲染正常（默认字体无中文字形，必须走助手库的 CJK 字体加载）、mp4 时长合理。任何一步失败，按 `references/blender-headless.md` 的排错表处理。

> 🛑 STOP：渲染产物未通过自检（文件缺失 / 中文豆腐块 / mp4 不可播）→ 不得进入 Stage 4；先排错，修不好走下方降级链。

**限时与降级**：单件渲染超过 5 分钟无产物 → 降帧（24→12）、降采样（48→16）、减视角，仍失败 → 降级为静态 PNG + 文内说明，并在交付物注明降级路径。禁止无限等待，禁止交付未真实运行的伪产物。

**环境降级链**（开工前探测，失败不硬上）：

| 探测失败 | 处理 |
|---|---|
| blender 路径不可执行 | 先问用户要路径；用户环境确实无 Blender → 降级为 SVG/Mermaid 示意图 + 主卡注明「未走 3D 及原因」 |
| 系统无中文字体（助手库 stderr 有 WARN） | 标注改用英文 + 主卡开头注明；禁止交付豆腐块图 |
| CLI 参数报错 / 渲染报错 | 对照 `references/blender-headless.md` 排错表逐条处理，报错原文贴给排错，不凭记忆猜 |

## Stage 4 — 讲清本质

- **一句话本质**：一句主谓宾点出「它到底是什么」，禁止循环定义。
- **通俗类比**（1–2 个）：类比后必须紧跟**类比失效边界**，防止误用。
- **为什么存在**：它诞生的动机，没有它会怎样。
- **硬性收口**：本质句必须能对应到 Stage 3 画面中的具体镜头（如「本质是 XX——对应等轴视角里最上层那块红色核心」）。对应不上，说明 Stage 3 选错了主体，回炉。

## Stage 5 — 自检闭环

1. **自检题 3–5 道**（含答案要点）：覆盖推理链起点、中间推导、边界反例。
2. **3D 复述测试**：把三张视角图交给用户，请用户看着图把推理链讲一遍。讲不出或讲错的位置 = 推理链的断点。
3. **缺口回流**：断点定位到 Stage 1（原子事实缺）或 Stage 2（依赖缺）→ 只补对应阶段后重新出片对应镜头，不整条重跑。

> 🔴 CHECKPOINT：交付前对照「质量约束与反模式」表逐条自检；任一命中 → 回对应 Stage 修复后重检，再进交付物规范。

## 交付物规范

统一目录，文件名**强制中文**（非法字符替换为「－」）：

```
[主题]/
├── [主题]—3D学习流水线.md      # 主卡，固定骨架见下
├── [主题]_scene.py             # 场景脚本（可复跑）
└── render/
    ├── 01-主视角.png  02-等轴视角.png  03-俯视角.png
    └── [主题]—360环绕.mp4
```

主卡固定骨架：

```
# [主题] — 3D 学习流水线卡
## 一句话本质
## 第一性原理拆解（假设 / 原子事实 / 推理链）
## 体系坐标（三层 DAG + 跨学科坐标）
## 3D 可视化（嵌入渲染图与环绕视频，标注隐喻/实体）
## 通俗理解（类比 + 失效边界）
## 边界与反例
## 自检题（含答案要点）
## 复述测试记录与缺口回流
## 参考来源
```

## 质量约束与反模式

| 反模式 | 替代做法 |
|---|---|
| 编造事实 / 来源 | 标「待核验」+ 给验证路径 |
| 交付未渲染的"想象图" | 真机渲染 + 自检通过才交付 |
| 中文标注用默认字体（豆腐块） | 一律走助手库 CJK 字体加载 |
| 为炫技堆镜头 | 每个镜头对应推理链的一步 |
| 隐喻当实体交付不说明 | 隐喻表达必须显式标注 |
| 渲染卡死干等 | 限时 5 分钟，降帧 / 降采样 / 降级静态图 |
| 2D 能讲清硬上 3D | 用户点名 Blender/3D 除外；否则先确认用户确实要 3D |
