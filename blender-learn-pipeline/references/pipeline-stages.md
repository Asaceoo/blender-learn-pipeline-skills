# 流水线阶段详册（pipeline-stages.md）

供 SKILL.md 五个 Stage 的深度展开。每个阶段给出 checklist，全过才放行下一段。

## Stage 1 拆到底层 — checklist

- [ ] 隐含假设 3–6 条，每条标注「承重 / 情景」
- [ ] 原子事实每条有来源类型（教科书 / 论文 / 官方文档 / 可复现实验），不可核验的标「待核验」
- [ ] 推理链每步可写成「由 A + B 推出 C」，链条从原子事实一路通到目标概念
- [ ] 推理链中没有跳步：读者能顺着每一步走到下一步

写法提醒：原子事实是「不可再分且可核验」的事实，不是「我觉得很重要的结论」。例：讲复利，原子事实是「利息计入本金后，下一期利息按新本金计算」（定义级），而不是「复利很厉害」（结论级）。

## Stage 2 建体系 — checklist

- [ ] 三层 DAG：核心层（主题本身）/ 支撑层（前置依赖）/ 延伸层（上层应用）
- [ ] DAG 用 Mermaid 表达，节点标「先学 / 后学」方向
- [ ] 跨学科坐标：该概念在其他学科的出现与视角差异（如「熵」在热力学 vs 信息论）
- [ ] **3D 主体选型完成**：已判定主体类型（层次结构 / 过程流转 / 空间关系 / 机制原理），且写明「选它的理由 = 它承载了推理链的哪几步」

3D 主体选型是本流水线的枢纽：选错主体，Stage 3 出的图再好看也讲不清本质。判定口诀——推理链里最「绕」的那步，往往就是需要被立起来看的那步。

## Stage 3 Blender 3D 可视化 — checklist

- [ ] 镜头清单 ≥3 静帧（主视角 / 等轴视角 / 俯视角）+ 1 环绕，每镜注明「对应推理链第几步」
- [ ] 场景脚本基于 `scripts/blender_learn.py` 助手库，只写建主体部分
- [ ] 真机渲染命令带 `--background --factory-startup`，输出目录已创建
- [ ] 产物自检：文件存在、非 0 字节、中文标注正常（看图确认，不凭日志猜）、mp4 可播放
- [ ] 超时 5 分钟即降级（降帧 / 降采样 / 减视角 / 静态图），并在主卡注明降级路径

隐喻标注：概念本身无空间性时（纯定义 / 纯数值），Blender 图是隐喻不是实体，主卡必须写「此为隐喻，对应关系是 XX」。

## Stage 4 讲清本质 — checklist

- [ ] 一句话本质：主谓宾完整，无循环定义（用 X 解释 X 即失败）
- [ ] 类比 1–2 个，每个类比后紧跟失效边界（「这个比方哪里不准」）
- [ ] 为什么存在 / 解决什么问题 / 没有它会怎样
- [ ] 本质句 ↔ 3D 镜头对应关系已写明；对应不上 → 回炉 Stage 2/3

## Stage 5 自检闭环 — checklist

- [ ] 自检题 3–5 道，覆盖：推理链起点 / 中间推导 / 边界反例；每题带答案要点
- [ ] 3D 复述测试：用户看三张视角图讲推理链；断点记录进主卡「复述测试记录」
- [ ] 缺口回流：断点定位到 Stage 1（事实缺）或 Stage 2（依赖缺），只补对应段 + 重出对应镜头

## 主卡骨架（复制即用）

```
# [主题] — 3D 学习流水线卡
## 一句话本质
## 第一性原理拆解（假设 / 原子事实 / 推理链）
## 体系坐标（三层 DAG + 跨学科坐标）
## 3D 可视化（嵌入 render/ 产物，标注隐喻/实体 + 镜头↔推理链对应表）
## 通俗理解（类比 + 失效边界）
## 边界与反例
## 自检题（含答案要点）
## 复述测试记录与缺口回流
## 参考来源
```
